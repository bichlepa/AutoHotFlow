# Square root

The action **Square root** calculates the square root of a number.

## Settings

### Output variable name

Name of the variable which will contain the result.

### Input number

The input number. A negative number gives an empty result, and a warning is written to the log.

## Remarks

The square root of a whole number is a whole number if it is exact (the square root of `16` is `4`). Any other result is a decimal number.
