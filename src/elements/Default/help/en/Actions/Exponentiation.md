# Exponentiation

The action **Exponentiation** raises a number to a power.

## Settings

### Output variable name

Name of the variable which will contain the result.

### Base

The base, a number.

### Exponent

The exponent, a number.

## Remarks

The formula of the calculation is: `Base ^ Exponent = Result`

The power of two whole numbers is a whole number if it is exact (`3` to the power of `2` is `9`); a negative exponent gives a decimal number.

Zero to a negative power, and a negative base to a fractional power, have no result: the variable then gets an empty result, and a warning is written to the log.
