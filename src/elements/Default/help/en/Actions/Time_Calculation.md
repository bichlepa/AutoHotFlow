# Time calculation

The action **Time calculation** adds an amount of time to a time stamp.

## Settings

### Output variable name

Name of the variable which will contain the result, a time stamp in the form `YYYYMMDDHH24MISS`.

### Input time

The time stamp to which the time is added, a text or an expression, for example the variable of a time stamp. It must be a valid time stamp; otherwise the action ends with an exception.

### Time to add

The amount to add, in the unit below. A whole number is expected; a decimal fraction is cut off.

### Which unit

Seconds, Minutes, Hours or Days.

## Remarks

A negative amount subtracts the time.
