# Set volume

The action **Set volume** sets the master volume of the first sound device.

## Settings

### Action

Specify which action should be done.

### Mute settings

If **Set mute state** is selected, specify which mute state to set: on, off or toggle.

### Absolute volume

If **Set a specified volume** is selected, specify the new volume from 0 to 100 %.

### Relative volume

If **Increase or decrease volume** is selected, specify by how many percent the volume should be increased (a positive number) or decreased (a negative number).

## Remarks

If the change fails, for example because the sound device is not available, the action ends with an exception.
