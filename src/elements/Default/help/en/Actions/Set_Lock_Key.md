# Set lock key

The action **Set lock key** sets the state of Caps Lock, Num Lock or Scroll Lock.

## Settings

### Which lock key

**Caps lock**, **Num lock** or **Scroll lock**.

### Status to set

**On** and **Off** set the key once. **Toggle** changes the key to the opposite of its current state.

**Always on** and **Always off** keep the key on or off, until a flow sets the key to **On**, **Off** or **Toggle** again. AutoHotkey then installs the keyboard hook.
