# Absolute number

The action **Absolute number** writes the absolute value of a number into a variable. The absolute value of a negative number is its positive counterpart, `-2` gives `2`; a positive number stays as it is.

## Settings

### Output variable name

Name of the variable which will contain the result.

### Input number

The input number, a number or an expression. If the value is not a number, the action ends with an exception and the flow goes on at the exception connection.
