# Change character case

The action **Change character case** writes a string in upper case, in lower case, or with the first letter of every word in upper case, to a variable.

## Settings

### Output Variable name

The variable that receives the result. It may be the same variable as the input string.

### Input string

The string to convert.

### Which case

**Uppercase** writes every letter in upper case.

**Lowercase** writes every letter in lower case.

**First character of a word is uppercase** (title case) writes the first letter of every word in upper case and the other letters of the word in lower case: "hello WORLD" becomes "Hello World".

Letters outside the English alphabet (for example "ä" or "é") are converted too.

## Examples

"Hello World" in uppercase is "HELLO WORLD"; in lowercase it is "hello world".
