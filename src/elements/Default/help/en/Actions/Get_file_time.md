# Get file time

The action **Get file time** retrieves a datetime stamp of a file or folder.

## Settings

### Output variable name

Name of the variable which will contain the result.

### File path

Name and path of the file. The file path is assumed to be in the working directory if an absolute path isn't specified.

### Which time

Specify whether the **Modification time**, **Creation time** or the **Last access time** should be retrieved
