# Set element parameter

The action **Set element parameter** changes a parameter of an element

## Settings

### Which flow

Choose a flow.

### Which trigger

Choose an element.

### Which parameter

Choose an element parameter.

### New value

Definde the new value. After selection of a parameter, one of the controls will be enabled where the new value can be set.

## Remarks

If a parameter of a trigger is changed, the trigger will be disabled and reenabled. This will activate the new parameter.
