# Minimize all windows

The action **Minimize all windows** minimizes every window of the user, not only the windows of the flow. The action **Undo** restores the windows that the last minimize minimized.

> **Warning:** The action changes the windows of the whole desktop. A flow that minimizes all windows can disturb the work of the user.

## Settings

### Event

**Minimize all windows**: all windows are minimized.

**Undo**: the windows minimized by the last minimize are restored.
