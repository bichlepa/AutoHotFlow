# User idle time

The trigger **User idle time** triggers whenever the user is inactive for a specified amount of time.

## Settings

### Period of time

The amount of time the user has to be idle before the trigger triggers.

### Method

If **Method: Default** is selected, every physical user input and simulated user input (e.g. using action **Send keystrokes**) will reset the timer.

If **Method: Physical** is selected, only physical user input will reset the timer.
