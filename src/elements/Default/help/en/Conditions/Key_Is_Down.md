# Key is down

The condition **Key is down** checks whether a key is being held down.

## Settings

### Key name

Name of the key which will be checked.

### Which key state

If **Logical** is selected, the result will be **yes** if the key is physically held down and if any other flow holds the key.

If **Physical** is selected, the result will be **yes** only if the key is physically held down.

## Remarks

The available keys are listed in the [key list](../../../../../../assets/help/en/Key_list.md).
