# String contains text

The condition **String contains text** checks whether a string contains the specified text.

## Settings

### Input string

A string its contents will be read from.

### Text to search

The string to search for.

### Search text position

Specify whether the input string must start or end with the searched text or just contain it anywhere.

### Case sensitivity

If **Case insensitive** is selected, the character case will be ignored. For example if the input string is “Hello World”, the search text “world” will match.

If **Case sensitive** is selected, the character case will not be ignored.
