# String contains text

The condition **String contains text** checks whether a string starts with, ends with or contains a text. It ends with "yes" if it does and with "no" if it does not.

## Settings

### Input string

The string to check.

### Text to search

The text to look for. It must not be empty.

### Search text position

**Starts with**: the string begins with the text.

**Ends with**: the string ends with the text.

**Contains anywhere**: the text occurs somewhere in the string.

### Case sensitivity

If **Case insensitive** is selected, the character case is ignored: "Hello World" contains "world".

If **Case sensitive** is selected, the character case matters.

## Remarks

The condition has two results, so it is used with the "yes" and "no" connections of the flow.
